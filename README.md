# Swiggy Landing Page Clone 🍔

A pixel-aligned recreation of the **Swiggy** landing page UI built from scratch using **HTML5** and **Tailwind CSS**.

> **Note:** 100% hand-coded without AI assistance to practice core frontend fundamentals and layout design.

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS** (v4 Browser CDN)
- **Remix Icon** (Icons)
- **Custom Fonts** (Swiggy Gilroy)

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sachin07-a/tailwind-swiggy.git
   ```
2. Open `index.html` in any web browser.

---

## 📸 Features

- Clean responsive layout using Tailwind CSS utility classes
- Header navigation bar with logo, links, and action buttons
- Search & location bars
- Service cards (Food Delivery, Instamart, Dineout) with hover states
- Floating food and grocery assets for brand feel
